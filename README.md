RTPFightQueue

A lightweight RTP Fight Queue and RTP Zone plugin for Paper 26.2.

✨ Features

- 🎯 RTP Fight Queue
- 🌍 Configurable RTP Zones
- 🖥️ Queue GUI
- ⚙️ Configurable settings
- 🔐 Separate player and admin permissions
- 🔄 Easy configuration reload
- 📦 Automatic Maven builds with GitHub Actions

📥 Installation

1. Download the latest "RTPFightQueue.jar" from Releases.
2. Put the ".jar" file into your server's "plugins" folder.
3. Restart your Paper server.
4. Configure the plugin in:
   "plugins/RTPFightQueue/config.yml"

🎮 Commands

Player

"/rtpqueue"

Opens the RTP Fight Queue GUI.

Admin

"/rtpzone <wand|pos1|pos2|create|enable|disable|info|reload>"

Used to create and manage RTP queue zones.

🔑 Permissions

Permission| Default| Description
"rtpqueue.use"| true| Use the RTP Fight Queue
"rtpqueue.admin"| op| Manage RTP zones and plugin settings

⚙️ Configuration

The main configuration file is:

"plugins/RTPFightQueue/config.yml"

You can customize the queue and RTP zone settings from there.

🛠️ Requirements

- Paper 26.2
- Java 21
